# 📣 Portfolio Introduction

Hi, I'm **Pedro Roberts**, a marketing analytics specialist based in Cape Town, South Africa.

It includes:

- Structured CSV data from YouTube, Meta, and website analytics

- A full ERD diagram  
- A professional README explaining the workflow
