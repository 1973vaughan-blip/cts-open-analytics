# 🌟 CTS Open Analytics — Project Overview

**CTS Open Analytics** is a complete, end‑to‑end marketing analytics workflow built using SQL, Supabase‑ready schemas, and multi‑touch attribution logic.

This project demonstrates how raw CSV exports from YouTube, Meta, and website analytics can be transformed into structured insights using clean data modeling and modular SQL queries.

---

## 🔍 What This Project Shows

### ✔ SQL proficiency  
Complex queries across retention, attribution, ROAS, and multi‑touch analytics.

### ✔ Data modeling  
A clean, three‑table schema designed for Supabase/PostgreSQL.

### ✔ Multi‑channel thinking  
Combining YouTube, Meta, and website data into unified insights.

### ✔ Documentation quality  
Professional README, ERD, run instructions, and portfolio introduction.

### ✔ Practical business value  
Every query produces actionable marketing insights.
